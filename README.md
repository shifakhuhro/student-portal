# student-portal

A minimal full-stack Student Portal with:
- Backend API (Node.js HTTP server)
- Frontend UI (HTML/CSS/JS)
- In-memory student CRUD (Create, Read, Update, Delete)

## Run locally

```bash
npm install
npm start
```

Open: `http://localhost:3000`

## Run tests

```bash
npm test
```

## API

- `GET /api/students`
- `POST /api/students`
- `PUT /api/students/:id`
- `DELETE /api/students/:id`
